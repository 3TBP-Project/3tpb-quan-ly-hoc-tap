## 1. Thống nhất cách xây dựng API giữa Backend và Frontend

TV2 và TV3 trao đổi trực tiếp để chốt cách hai bên nói chuyện với nhau. Đây là nội dung chiếm phần lớn thời gian họp.

**Về mô hình tổng thể:** nhóm làm theo kiểu **client – server tách rời**. React chạy trên trình duyệt, Express chạy trên máy chủ, hai bên trao đổi bằng JSON qua API. Server **không dựng sẵn HTML** gửi xuống.

**Về cách tổ chức code bên trong server:** giữ nguyên **kiến trúc 3 lớp** đã khởi tạo từ Ngày 1.

- Controller nhận request, kiểm tra dữ liệu đầu vào, trả response. Không viết truy vấn cơ sở dữ liệu ở đây.
- Service xử lý nghiệp vụ và kiểm tra quyền sở hữu. Không đụng tới `req` và `res`.
- Repository truy vấn cơ sở dữ liệu. Không chứa logic nghiệp vụ.

Hai khái niệm này không mâu thuẫn nhau: client – server nói về việc hệ thống chia làm hai bên chạy ở hai nơi, còn 3 lớp nói về cách sắp xếp code bên trong phần server.

**Các quy ước đã chốt:**

| Nội dung                  | Thống nhất                                                                                                                                                 |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Đường dẫn gốc             | Mọi API bắt đầu bằng `/api`                                                                                                                                |
| Định dạng dữ liệu         | JSON cả hai chiều                                                                                                                                          |
| Xác thực                  | JWT, gửi kèm trong header `Authorization: Bearer <token>`                                                                                                  |
| Nhóm đường dẫn theo quyền | `/api/auth` và `/api/courses` cho mọi người; `/api/me` cho người đã đăng nhập; `/api/teacher` cho giảng viên; `/api/admin` cho quản trị                    |
| Mã trạng thái             | 200 thành công, 201 tạo mới, 400 dữ liệu sai, 401 chưa đăng nhập, 403 không đủ quyền, 404 không tìm thấy, 409 trùng dữ liệu, 422 vi phạm quy tắc nghiệp vụ |
| Thông báo lỗi             | Server trả thông báo **bằng tiếng Việt**, React hiển thị nguyên văn, không tự viết lại                                                                     |
| Phân trang                | Làm ở phía server, không tải hết rồi mới chia trang ở trình duyệt                                                                                          |

**Về phân quyền:** việc ẩn hiện menu trên giao diện chỉ để thuận tiện cho người dùng. Quyền thật do server kiểm tra bằng middleware. TV3 không được coi việc ẩn nút là đã phân quyền xong.

**Cách làm việc khi API chưa xong:** TV3 dùng dữ liệu giả để dựng giao diện trước, TV2 làm API song song. Khi API xong thì TV3 thay dữ liệu giả bằng lời gọi thật. Hai bên thống nhất **hình dạng dữ liệu trả về trước**, rồi mới ai làm việc nấy.

**Chia việc phần form đăng ký và đăng nhập.** Hai bạn phát hiện có chỗ trùng việc nên chốt lại:

- TV2 chỉ làm form thô, tối thiểu, dùng để tự kiểm thử backend. Không cần đẹp, không cần responsive.
- TV3 làm bản giao diện chính thức ở Ngày 4. Đây là bản dùng để trình bày Mốc 1.

## 2. Chốt wireframe

TV3 trình bày bản wireframe 6 màn hình và giải thích từng màn hình.

| Màn hình                  | Kết luận |
| ------------------------- | -------- |
| Danh sách khóa học        | Chốt     |
| Chi tiết khóa học         | Chốt     |
| Học bài                   | Chốt     |
| Làm bài trắc nghiệm       | Chốt     |
| Trang giảng viên          | Chốt     |
| Trang quản trị người dùng | Chốt     |

Nhóm thống nhất lấy bản wireframe này làm căn cứ dựng giao diện. Từ giờ nếu muốn đổi bố cục thì phải báo trong nhóm, không tự ý sửa.

Các điểm được nhắc riêng khi duyệt:

- Trang chi tiết khóa học chỉ hiện **tên bài học**, chưa cho xem nội dung. Người chưa ghi danh không được xem nội dung bài.
- Màn hình làm bài trắc nghiệm phải có **đồng hồ đếm ngược**. Nhóm lưu ý đồng hồ này chỉ để người dùng nhìn, còn việc tính giờ thật do server làm.
- Mỗi màn hình cần kèm bản cho điện thoại, do yêu cầu giao diện phải responsive.

Ảnh wireframe lưu tại `docs/wireframes/`.
